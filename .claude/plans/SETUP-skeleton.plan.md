# Plan: SETUP · Walking skeleton (local first)

**Source spec**: specs/SETUP-skeleton.md
**Complexity**: Large (first PR: package.json, full tooling, DB, auth, two root layouts)

## Summary

Scaffold the Next.js 16.3 app by hand in the existing (non-empty) repo: `package.json` with the scripts CLAUDE.md
lists, validated env (`lib/env.ts`, 8 variables, imported by `next.config.ts`), Drizzle with a minimal `products`
table plus the Better Auth tables, a seed (product `demo` and an admin account), Better Auth (password sign-in for
admins only, magic link that stores the link instead of sending it, `nextCookies()` last), and the frozen contract
`getSession()` / `requireAdmin()` in `lib/dal/session.ts`. `/demo` shows "demo" read from Postgres. `/admin` is
protected. `pnpm check` passes with lint-staged in a pre-commit hook, and `AGENTS.md` is generated by Next.
Everything runs locally: native Postgres 16, database `msb_feat_setup_skeleton`, `AI_MODE=mock`.
