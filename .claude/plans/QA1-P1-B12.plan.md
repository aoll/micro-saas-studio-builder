# Implementation Plan: QA1-P1-B12 · Vrais statuts HTTP pour /admin/ops et /admin sans session

**Source spec**: specs/qa/QA1-P1-B12-statut-http.md
**Réf**: .claude/qa/reports/2026-09-25-full.md › B12 · specs/DEMO-mode.md › Acceptation 3 · specs/SETUP-skeleton.md › Acceptation 4
**Contract**: `requireAdmin`, `getSession`, `lib/auth.ts`, `lib/schemas/**`, `lib/db/schema.ts` unchanged.
**Starts after QA1-P1-B4 is merged** (B4 creates `proxy.ts` for the `anonymous_id` cookie): merge the integration branch first and compose with its `proxy()`.

## Root cause

- Streaming HTTP contract (Next 16.3 docs `02-guides/streaming.md` › The HTTP contract, `03-file-conventions/loading.md` › Status Codes): once a Suspense fallback is sent, the status is `200`; a later `notFound()` becomes `NEXT_HTTP_ERROR_FALLBACK;404` in the stream, a later `redirect()` a client-side redirect.
- `/admin/ops`: `ops/page.tsx` awaits `getSession()` then `notFound()`, but every page under `/admin/**` is wrapped by the implicit Suspense of `app/(backoffice)/admin/loading.tsx`; `getSession()` reads `headers()`, so the shell (layout + `PortfolioSkeleton`) leaves in 200 first.
- `/admin`: `requireAdmin()` runs in `<Portfolio>` under `<Suspense>`: the static shell (« Portefeuille », « Nouveau produit ») leaves in 200 to an anonymous visitor.
- 404 in English: no `not-found.tsx` under `app/(backoffice)/**`.

## Decision

- **Phase 1 — optimistic guard in `proxy.ts`** (cookie presence only via `getSessionCookie` from `better-auth/cookies`; no DB, no role): no session cookie → real 307 to `/admin/login`, or a real 404 (small French HTML) for `/admin/ops*`. The real check stays `requireAdmin()` in the DAL (docs/04).
- **Phase 2 — role check before any Suspense**: delete `app/(backoffice)/admin/loading.tsx` (docs/04: « Pas besoin d'un loading.tsx par page » — every admin page already has its own `<Suspense>` + skeleton, the portfolio included), `export const instant = false` on `ops/page.tsx` (hidden owner page, blocking is acceptable), and a French `app/(backoffice)/admin/ops/not-found.tsx`. Scope extended by the orchestrator to these files.
- Rejected: reading the role in the proxy (docs/04 forbids authorization in proxy), `x-pathname` header + `headers()` in the backoffice root layout (makes the whole BO blocking), `requireAdmin()` at the top of `admin/page.tsx` (makes the portfolio blocking).
